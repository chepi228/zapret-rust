# zapret-rust 1.4

**YouTube, Discord и Telegram Desktop в Windows 10/11 x64.** Если провайдер ограничивает доступ через DPI, zapret-rust помогает подобрать стратегию для вашего подключения. Из одного меню можно запустить обход, проверить загрузку вложений Discord и подключить Telegram к локальному мосту.

**[Скачать ZIP для Windows x64](https://github.com/chepi228/zapret-rust/releases/download/v1.4/zapret-rust-v1.4-windows-x64.zip)** · [Все файлы релиза](https://github.com/chepi228/zapret-rust/releases/tag/v1.4) · [Что нового в 1.4](CHANGELOG.md) · [English](README.en.md)

## Первый запуск в Windows

1. Скачайте ZIP по ссылке выше. Распакуйте архив целиком в постоянную папку, например `C:\Tools\zapret-rust`.
2. Откройте `zapret-rust.exe` и подтвердите запрос Windows. При первом открытии программа обновит шесть общих списков и проверит совместимость ПК. Отчёт сохраняется в `runtime\pc-check-last.json`.
3. Нажмите **1**, затем откройте сервис, ради которого установили программу. Если страницы открываются, проверьте также видео, картинки или голосовую связь, которыми обычно пользуетесь.
4. Если что-то по-прежнему долго загружается, выберите **3 → 1**. Программа сама переберёт профили для текущего подключения. Запускайте замер между матчами и звонками — на время сравнения программа останавливает рабочий обход.

Если GitHub Raw недоступен, программа пробует GitHub API и подключение через настройки прокси Windows. При перебоях она использует списки из архива или последнего успешного обновления. В **7 → 8** видна дата обновления, там же можно повторить загрузку вручную. После неудачного первого обновления с рабочими локальными списками автоматическая попытка повторится при открытии меню через 10 минут или позже.

При переходе со старой сборки с BAT распакуйте новый ZIP в отдельную папку. Для переноса настроек и пользовательских списков скопируйте `runtime\settings.ini` и свои файлы `lists\*-user.txt` при закрытых меню обеих сборок.

## Чем отличается от сборки Flowseal

Оба проекта помогают обходить DPI и позволяют проверить стратегии на своём подключении. Сборка Flowseal предлагает готовые BAT-конфигурации. zapret-rust использует стратегии Flowseal и наработки zapret2 в собственном Windows-пакете с движком, контроллером и мостом Telegram на Rust.

| Задача | Flowseal/zapret-discord-youtube | zapret-rust |
| --- | --- | --- |
| Запустить стратегию | Открыть один из файлов `general*.bat`. Через `service.bat` выбранную конфигурацию можно установить как службу. | Открыть `zapret-rust.exe`. Пункт **1** запускает выбранный профиль, **5** позволяет сменить его вручную, **7 → 6** включает автозапуск. |
| Найти рабочий профиль | В `service.bat` выбрать **Run Tests → Standard tests → All configs**. Доступны также **DPI checkers**. | **3 → 1** сравнивает до 18 профилей с замером без обхода. Лучшие кандидаты проходят повторную проверку. **3 → 2** проверяет все 36 профилей. |
| Подключить Telegram Desktop | В README дана ссылка на отдельный проект **tg-ws-proxy**. | **4 → 1** запускает встроенный мост и открывает ссылку подключения в Telegram. Для загрузок мост держит отдельный пул соединений. |
| Разобраться со сбоем Discord | В `service.bat` есть диагностика, очистка кэша Discord и обновление hosts для голосового чата. | **6** скачивает контрольное вложение и сверяет SHA-256 файла. **8 → 12** отдельно проверяет голосовую связь. |

[Репозиторий Flowseal и его руководство](https://github.com/Flowseal/zapret-discord-youtube) · [TG WS Proxy от Flowseal](https://github.com/Flowseal/tg-ws-proxy) · [Исходный проект zapret2](https://github.com/bol-van/zapret2)

## Как читать автоподбор

Строка **«Без обхода»** показывает исходную доступность на вашем подключении. Быстрый подбор проверяет до **18 стратегий**. Сначала он замеряет текущую стратегию на полном наборе целей, затем сравнивает кандидатов на коротком общем наборе. В него входят контрольные адреса, медиа Discord, иконка Roblox и проблемные сервисы этого подключения. Полный набор проходят три лидера и дополнительные кандидаты, которые вместе покрывают все замеченные восстановления доступа. Если один контрольный сайт перестал отвечать, его может заменить запасной. Если короткий отбор не подтвердил два контрольных адреса, все оставшиеся кандидаты проходят полный замер. Выбрать полный перебор можно в **3 → 2**.

| Что видно во время замера | Как это читать |
| --- | --- |
| `32/68 (+4)`, зелёный | Открылись 32 из 68 адресов. Это на четыре больше, чем без обхода. |
| `28/68 (=)`, обычный цвет | Число ответивших адресов совпало с исходным. |
| `26/68 (-2)`, красный | Ответили на два адреса меньше. |
| Жёлтая строка | Контрольная проверка нестабильна или набор адресов изменился. Сравнение требует повторного замера. |
| `балл` и `лидер по доступности` | Оценка учитывает повторные попытки и ухудшение связи с контрольными адресами. Она помогает выбрать кандидата для финала. |

В итоговой таблице штатного теста пробный балл скорости отсчитывается от опорного профиля (0). Для каждого сопоставимого адреса программа вычисляет `100 × (время опорного − время кандидата) / большее из двух времён`. Она усредняет баллы сначала по адресам внутри группы, затем поровну по группам. Знак «+» означает выигрыш. Потеря рабочего сервиса исключает переход по скорости. При смене порядка проверок автоподбор берёт меньший из двух баллов каждой группы и усредняет их. Для перехода нужны не меньше +3 баллов по этому расчёту и в каждом финале отдельно.

**Финал проверяет профиль в рабочей конфигурации.** В итоговой таблице зелёный означает пройденный финал, красный — проваленный. Если видите «Не применено», в сводке указаны причина и сохранённая стратегия. Последний результат доступен в **3 → 5**, а путь к подробному текстовому отчёту выводится внизу сводки.

Если выбор решило открытие одного сервиса с первой попытки, финал сравнит именно его. Когда выигрыш сохраняется, программа проверяет обе стратегии в обратном порядке. Если разница исчезает и других подтверждённых преимуществ нет, текущая стратегия остаётся основной.

**4 → 4** показывает ответ моста Telegram и время соединения с медиа-центрами DC2 и DC4. Для проверки скачивания запустите меню из среды, где заданы `ZAPRET_TEST_TG_API_ID`, `ZAPRET_TEST_TG_API_HASH` вашего приложения Telegram и `ZAPRET_TEST_TG_BOT_TOKEN` отдельного тестового бота. Программа скачает небольшой публичный стикер через этот же мост. В отчёте видны результаты всех трёх проверок.

**Ctrl+C** отменяет подбор. На время замеров отключается выделение текста мышью в классической консоли Windows. Благодаря этому случайный щелчок больше не оставляет прогон на одной строке.

## Частые действия

| Задача | Пункт главного меню |
| --- | --- |
| Запустить обход или перечитать настройки | **1** — запуск или перезапуск |
| Остановить работающие экземпляры zapret | **2** — остановка затрагивает экземпляры из других папок |
| Проверить все профили или отдельно проверить браузер | **3 → 2** — расширенный подбор, **3 → 3** — подбор с проверкой браузера |
| Выбрать профиль самостоятельно | **5** — список стратегий |
| Посмотреть, что влияет на подключение | **6** — диагностика сети, VPN, прокси и конфликтов |
| Включить запуск вместе с Windows | **7 → 6** — автозапуск |
| Проверить доступность новой версии | **7 → 9** — обновление программы |
| Узнать, где обрывается запрос | **8 → 11** — проверка DNS, TCP, TLS и HTTP |
| Удалить регистрацию программы в Windows | **7 → 11** — удаление из Windows |

### Telegram Desktop

Выберите **4 → 1** и подтвердите подключение прокси в Telegram Desktop. Мост слушает локальный адрес `127.0.0.1`. Если понадобится сменить порт, откройте **4 → 3**. Остановить мост можно через **4 → 2**.

### Если сервис работает частично

- **YouTube открывается, но ролик не играет.** Пункт **8 → 13** открывает публичный ролик без звука во временном профиле браузера. Проверка засчитывает минимум пять секунд воспроизведения и десять показанных кадров. В отчёте указаны длительность, число кадров и паузы от секунды.
- **Для сравнения домашней и мобильной сети** запустите **8 → 13** и **8 → 12** на каждом подключении. Для проверки Discord по очереди произнесите и повторите фразы с собеседником. В папке `runtime` сохраняются отдельные файлы `youtube-check-<id>.txt` и `voice-check-<id>.txt` для каждого запуска.
- **У одного провайдера сайт открывается, а у другого пропадают картинки.** Пункт **6** сравнивает IPv4- и IPv6-адреса от системного и защищённого DNS. Он также проверяет сервер иконок Roblox и показывает имя, для которого удалось подтвердить альтернативный адрес по TLS.
- **Discord открывается, но картинки зависают.** Пункт **6** скачивает контрольный файл с сервера медиа Discord и проверяет его целиком. Если загрузка через DNS не проходит, а через проверенный адрес работает, меню предложит закрепить адрес для медиа. Результат автоподбора доступен через **3 → 5**, диагностика голосовой связи Discord — через **8 → 12**.
- **Браузер и автоподбор показывают разные результаты.** Пункт **8 → 10** проверяет фактическое подключение браузера по HTTP/2 и HTTP/3. Если пользуетесь VPN или системным прокси, пункт **6** поможет проверить условия замера.
- **Автоподбор прервался из-за подключения.** Если исходная сеть быстро вернулась, подбор один раз повторит замеры с самого начала. При переходе на другую сеть запустите **3 → 1** на новом подключении. Причину последней остановки можно посмотреть в **3 → 5** или включить в отчёт через **8 → 4**.
- **Подбор сообщает о нехватке контрольных серверов.** В исходном замере должны успешно ответить два разных сервера. Подбор повторно проверяет подключение и показывает количество ошибок DNS, если проверка снова не удалась. Если при переборе завершится движок отдельного дополнительного профиля, его имя и код выхода появятся в отчёте.
- **Сайт отвечает только по части адресов из DNS.** Если первый адрес затягивает установку защищённого соединения, HTTPS-проверка, загрузчик списков и мост Telegram пробуют второй адрес через 250 мс. При явном отказе следующий адрес пробуется сразу. Программа проверяет сертификат для исходного имени и отправляет запрос один раз по готовому соединению. Если запасной адрес восстановил доступ после зависания TLS, автоподбор учитывает это при оценке доступности. Если первым успел исходный адрес, его замер остаётся пригодным для сравнения задержки.
- **Много таймаутов одновременно.** При более чем 16 отказах подбор повторяет часть запросов к разным сервисам с меньшим параллелизмом. Если два разных сервиса отвечают успешно, он также перепроверяет остальные адреса с таймаутом или ошибкой TCP. В итогах видно, сколько таких серий потребовали расширенного повтора.

Список всех пунктов, работа с пользовательскими списками и восстановление после обновления описаны в [руководстве для Windows](https://github.com/chepi228/zapret-rust/blob/v1.4/docs/windows.md).

## Форматы загрузки и Linux

Архивы для ручной установки (ZIP, 7z и RAR) содержат одинаковую папку `zapret-rust`. ZIP открывается штатными средствами Windows. Для двух других форматов нужен совместимый архиватор. [ZIP](https://github.com/chepi228/zapret-rust/releases/download/v1.4/zapret-rust-v1.4-windows-x64.zip) · [7z](https://github.com/chepi228/zapret-rust/releases/download/v1.4/zapret-rust-v1.4-windows-x64.7z) · [RAR](https://github.com/chepi228/zapret-rust/releases/download/v1.4/zapret-rust-v1.4-windows-x64.rar) · [SHA256SUMS.txt](https://github.com/chepi228/zapret-rust/releases/download/v1.4/SHA256SUMS.txt)

Для Linux выпускается отдельный установщик. Он скачивает зафиксированный upstream **zapret2 v1.0.7**, проверяет SHA-256 и запускает его интерактивную настройку. Для подготовки файлов без установки добавьте `--prepare-only`. [Скачать установщик](https://github.com/chepi228/zapret-rust/releases/download/v1.4/zapret-rust-v1.4-linux-install.sh) · [Руководство для Linux](https://github.com/chepi228/zapret-rust/blob/v1.4/docs/linux.md)

```sh
sh zapret-rust-v1.4-linux-install.sh
```

## Состав и лицензии

В стандартной сборке Windows x64 контроллер, фоновый процесс, пакетный движок, библиотека ring и мост Telegram реализованы на Rust. Встроенные стратегии входят в движок, пользовательские Lua-сценарии исполняет Luna Core. Для работы с трафиком используется сторонний драйвер WinDivert и системные API Windows. Исходники также содержат тестовые эталоны и сборки совместимости. [Сборка и варианты движка](https://github.com/chepi228/zapret-rust/blob/v1.4/native/zapret-ring-ffi/README.md#native-windows-engine)

Проект основан на zapret2 и использует наработки Flowseal. Код проекта распространяется по MIT, для сторонних компонентов действуют лицензии их авторов. [zapret2](https://github.com/bol-van/zapret2) · [Стратегии Flowseal](https://github.com/Flowseal/zapret-discord-youtube) · [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) · [MIT](licenses/LICENSE) · [Сторонние компоненты](licenses/THIRD-PARTY-NOTICES.md)

Диаграмма языков GitHub показывает состав исходников согласно правилам `.gitattributes`. [Правила подсчёта](https://github.com/chepi228/zapret-rust/blob/v1.4/.gitattributes)
