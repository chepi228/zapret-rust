# zapret-rust 1.1

zapret-rust помогает открыть YouTube, Discord и другие сервисы, когда провайдер ограничивает соединение через DPI. В Windows всё управление собрано в одном BAT-меню. Можно сравнить стратегии на своём подключении, включить локальный прокси для Telegram Desktop и посмотреть, на каком этапе перестаёт отвечать сервис.

## Первый запуск в Windows

1. Скачайте ZIP по ссылке выше. Распакуйте архив целиком в постоянную папку, например `C:\Tools\zapret-rust`.
2. Откройте `zapret-rust.bat` из распакованной папки и подтвердите запрос прав администратора. Держите BAT рядом с папками `bin`, `lists`, `strategies` и `tools`.
3. Нажмите **1**, затем откройте сервис, ради которого установили программу. Если страницы открываются, проверьте также видео, картинки или голосовую связь, которыми обычно пользуетесь.
4. Если что-то по-прежнему долго загружается, выберите **3 → 1**. Программа сама переберёт профили для текущего подключения. Запускайте замер между матчами и звонками — на время сравнения программа останавливает рабочий обход.

Если уже установлена **1.0**, откройте её BAT и выберите **7 → 9**. Подтвердите обновление и при запросе снова откройте BAT из той же папки. Встроенное обновление проверяет SHA-256 архива и сохраняет настройки, данные Telegram и пользовательские списки.

## Как читать автоподбор

Строка **«Без обхода»** показывает исходную доступность на вашем подключении. Быстрый подбор проверяет до **18 стратегий**. В комплекте 1.1 **86 целей**, включая контрольные адреса. Отдельно проверяются страницы, загрузка файлов, изображения и HTTP/3. Контрольные адреса и недоступные для измерения типы проб исключаются из счётчика ответов.

| Что видно во время замера | Как это читать |
| --- | --- |
| `32/68 (+4)`, зелёный | Открылись 32 из 68 адресов. Это на четыре больше, чем без обхода. |
| `28/68 (=)`, обычный цвет | Число ответивших адресов совпало с исходным. |
| `26/68 (-2)`, красный | Ответили на два адреса меньше. |
| Жёлтая строка | Контрольная проверка нестабильна или набор адресов изменился. Сравнение требует повторного замера. |
| `балл` и `лидер по баллу` | Оценка учитывает повторные попытки и ухудшение связи с контрольными адресами. Она помогает выбрать кандидата для финала. |

**Финал проверяет профиль в рабочей конфигурации.** В итоговой таблице зелёный означает пройденный финал, красный — проваленный. Если видите «Не применено», в сводке указаны причина и сохранённая стратегия. Последний результат доступен в **3 → 5**, а путь к подробному текстовому отчёту выводится внизу сводки.

**Ctrl+C** отменяет подбор. В версии 1.1 на время замеров отключается выделение текста мышью в классической консоли Windows. Благодаря этому случайный щелчок больше не оставляет прогон на одной строке.

## Частые действия

| Задача | Пункт главного меню |
| --- | --- |
| Запустить обход или перечитать настройки | **1** — запуск или перезапуск |
| Остановить работающие экземпляры zapret | **2** — остановка затрагивает экземпляры из других папок |
| Проверить все профили или отдельно проверить браузер | **3 → 2** — расширенный подбор, **3 → 3** — подбор с проверкой браузера |
| Выбрать профиль самостоятельно | **5** — список стратегий |
| Посмотреть, что влияет на подключение | **6** — диагностика сети, VPN, прокси и конфликтов |
| Включить запуск вместе с Windows | **7 → 6** — автозапуск |
| Проверить доступность новой версии | **7 → 9** — обновление программы |
| Узнать, где обрывается запрос | **8 → 11** — проверка DNS, TCP, TLS и HTTP |
| Удалить регистрацию программы в Windows | **7 → 11** — удаление из Windows |

### Telegram Desktop

Выберите **4 → 1** и подтвердите подключение прокси в Telegram Desktop. Мост слушает локальный адрес `127.0.0.1`. Если понадобится сменить порт, откройте **4 → 3**. Остановить мост можно через **4 → 2**.

### Если сервис работает частично

- **Discord открывается, но нет картинок или голоса.** Откройте последний результат через **3 → 5** и проверьте строки Discord. Для голосовой связи есть отдельная диагностика **8 → 12**.
- **Браузер и автоподбор показывают разные результаты.** Пункт **8 → 10** проверяет фактическое подключение браузера по HTTP/2 и HTTP/3. Если пользуетесь VPN или системным прокси, пункт **6** поможет проверить условия замера.
- **После смены сети профиль работает хуже.** Запустите **3 → 1** на том подключении, которым будете пользоваться. Пункт **8 → 4** собирает настройки и логи в один диагностический отчёт.

Список всех пунктов, работа с пользовательскими списками и восстановление после обновления описаны в [руководстве для Windows](https://github.com/chepi228/zapret-rust/blob/v1.1/docs/windows.md).

## Форматы загрузки и Linux

Архивы Windows содержат одинаковую папку `zapret-rust`. ZIP открывается штатными средствами Windows. Для двух других форматов нужен совместимый архиватор. [ZIP](https://github.com/chepi228/zapret-rust/releases/download/v1.1/zapret-rust-native-v1.1.zip) · [7z](https://github.com/chepi228/zapret-rust/releases/download/v1.1/zapret-rust-v1.1-windows-x64.7z) · [RAR](https://github.com/chepi228/zapret-rust/releases/download/v1.1/zapret-rust-v1.1-windows-x64.rar) · [SHA256SUMS.txt](https://github.com/chepi228/zapret-rust/releases/download/v1.1/SHA256SUMS.txt)

Для Linux выпускается отдельный установщик. Он скачивает зафиксированный upstream **zapret2 v1.0.7**, проверяет SHA-256 и запускает его интерактивную настройку. Для подготовки файлов без установки добавьте `--prepare-only`. [Скачать установщик](https://github.com/chepi228/zapret-rust/releases/download/v1.1/zapret-rust-v1.1-linux-install.sh) · [Руководство для Linux](https://github.com/chepi228/zapret-rust/blob/v1.1/docs/linux.md)

```sh
sh zapret-rust-v1.1-linux-install.sh
```

## Состав и лицензии

В стандартной сборке Windows x64 контроллер, фоновый процесс, пакетный движок, библиотека ring и мост Telegram реализованы на Rust. Встроенные стратегии входят в движок, пользовательские Lua-сценарии исполняет Luna Core. Для работы с трафиком используется сторонний драйвер WinDivert и системные API Windows. Исходники также содержат тестовые эталоны и сборки совместимости. [Сборка и варианты движка](https://github.com/chepi228/zapret-rust/blob/v1.1/native/zapret-ring-ffi/README.md#native-windows-engine)

Проект основан на zapret2 и использует наработки Flowseal. Код проекта распространяется по MIT, для сторонних компонентов действуют лицензии их авторов. [zapret2](https://github.com/bol-van/zapret2) · [Стратегии Flowseal](https://github.com/Flowseal/zapret-discord-youtube) · [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) · [MIT](licenses/LICENSE) · [Сторонние компоненты](licenses/THIRD-PARTY-NOTICES.md)

Диаграмма языков GitHub показывает исходники Rust согласно правилам `.gitattributes`. BAT, Linux-установщик и исторические эталоны исключены из этого подсчёта. [Правила подсчёта](https://github.com/chepi228/zapret-rust/blob/v1.1/.gitattributes)
