# Руководство для Windows

## Пункты меню

На главном экране только то, что нужно каждый день:

| Пункт | Что делает |
|---|---|
| 1 | Запустить / перезапустить обход |
| 2 | Остановить службы и процессы zapret (`winws`, `winws2`) из всех папок. Свободный драйвер WinDivert выгружается при подтверждённой принадлежности пакету |
| 3 | Автоподбор: 1 — быстрый поиск по TCP-семействам, 2 — полный, 3 — быстрый с проверкой браузера и HTTP-протоколов после теста |
| 4 | Telegram: встроенное Rust-ядро на основе TG WS Proxy от Flowseal |
| 5 | Выбрать стратегию вручную по номеру; полный список разбит на страницы (то же, что Настройки → 1) |
| 6 | Проверка обходов: подключение, VPN, прокси, игровые ускорители, другой обход; открываются ли прямо сейчас YouTube, Discord, Steam, GitHub и серверы NBA 2K27; IPv6, hosts Flowseal, серверы игр, частично заблокированные по IP; автосписок — и выбор, что исправить |
| 7 | Настройки (ниже) |
| 8 | Инструменты (ниже) |
| 9 | Уведомления: ошибки целостности, конфликты, обновления сборки и компонентов |
| 0 | Выход |

**7 — Настройки**, у каждой видно текущее значение:

| Пункт | Что делает |
|---|---|
| 1 | Основная стратегия по номеру строки или коду (`FS-EXP`, `Z2-BASE`). Здесь же видны круги автосмены |
| 2 | Автосмена стратегии при сбое: вкл/выкл (выкл — одна стратегия на всё, как у Flowseal) |
| 3 | Игровой фильтр. Можно выбрать игры по имени EXE, задать порты, включить TCP и UDP по отдельности или выключить фильтр |
| 4 | IPSet: loaded (как у Flowseal) / any (все адреса) / none |
| 5 | Автосписок сайтов: посмотреть, удалить сайт, очистить, вкл/выкл |
| 6 | Служба автозапуска с Windows: установить / удалить |
| 7 | Автонастройка по расписанию: вкл/выкл, журнал |
| 8 | Обновить списки (сети и домены для обхода, берутся у Flowseal) и проверить новые версии zapret-rust, zapret2 и Flowseal |
| 9 | Обновить zapret-rust до последнего релиза с GitHub: архив сверяется по SHA-256, настройки и ваши списки остаются |
| 10 | Уведомления Windows: служба обхода упала, Steam или Discord остались без сети после прокси, вышла новая версия |
| 11 | Удалить zapret-rust из Windows: обход, драйвер, службу, задачи, записи в hosts и права на папки — потом папку можно просто удалить |

**8 — Инструменты:**

| Пункт | Что делает |
|---|---|
| 1 | Трекер: NBA 2K27, Discord (голос) или любая программа по имени процесса |
| 2 | Сканер серверов игры. Запускайте во время входа в сетевой режим или подключения к матчу |
| 3 | Проверка провайдера: отчёт одним файлом, чтобы переслать |
| 4 | Отчёт: настройки, состояние и логи одним файлом |
| 5 | Диагностика: winws2 в видимом окне, по желанию с подробным логом |
| 6 | Исключить игру из обхода: сети, которые обход трогал по последнему трекеру, — в `ipset-exclude-user.txt` |
| 7 | Правила «напрямую» для Happ и других прокси: Steam, Discord и игры мимо прокси (файл на рабочий стол и в буфер обмена) |
| 8 | Discord не запускается: очистить его кэш (вход и настройки остаются), как у Flowseal |
| 9 | Пинг до игровых серверов: серверы матча NBA 2K27, сервисы 2K, регионы Amazon, Steam, Discord |
| 10 | Проверка текущего подключения браузером Edge/Chrome, HTTP/2 и HTTP/3. Сохраняет фактический протокол и отдельный отчёт |
| 11 | Этап сбоя подключения: DNS, TCP, TLS или HTTP. Несколько IPv4/IPv6, повторные попытки и ошибки сертификата |
| 12 | Discord Voice: наблюдение UDP, отдельный STUN-контроль и подтверждение двустороннего звука |

Проверка браузера использует временный профиль и проверяет основной документ YouTube, Discord и контрольного сайта. HTTP/1.1 и HTTP/2 реализованы в Rust. Для HTTP/3 программа выбирает WinHTTP при поддержке Windows или встроенный клиент Quinn с проверкой сертификатов через системное хранилище. Фактически согласованный протокол, ошибки и недоступные клиенты сохраняются в `runtime/web-check-last.txt` и `.json`. Эти наблюдения не измеряют воспроизведение видео, звук или игровой пинг.

Диагностика **Инструменты → 11** сохраняет DNS, TCP, TLS и HTTP отдельно для каждой попытки и выбранного IP. Rust-клиент использует Schannel, проверяет имя и доверие сертификату и читает ограниченные HTTP/1.1 HEAD-заголовки. `runtime/connection-check-last.json` ссылается на точный именной текстовый отчёт и его SHA256. Стратегия при проверке не меняется.

Для **Инструменты → 12** зайдите в голосовой канал Discord с собеседником и говорите во время наблюдения. Временный ETL содержит сетевые метаданные всех процессов; итоговый отчёт включает Discord. Звук не записывается. Независимый нативный процесс ограничивает срок собственного сеанса и следит за идентичностью родителя. После подтверждённой остановки ETL удаляется; при ошибке остаётся информация для очистки. STUN, UDP-метаданные и ваш ответ о работе звука сохраняются отдельно. Последний отчёт — `runtime/voice-check-last.json`. Только UDP-контроль: `bin\zapret-rust.exe voicecheck --args "{\"control_only\":true}"`.

На каждом экране свои номера, 0 — назад. Буквы прежних версий (T — трекер, S — служба, U — автонастройка и т. д.) тоже работают с любого экрана.

## Стратегии

Каждая стратегия — файл `strategies\altNN.txt` с секциями под все профили: QUIC, голос Discord, discord.media, YouTube, общий список, сети ipset-all, игровой TCP и игровой UDP.

Коды используются в меню, в новых отчётах и в выводе `strategies`. Команда `compose --alt WHITE-03 --dry-run` принимает код, ID файла или прежнее имя.

| ID | Код | Устройство |
|---|---|---|
| 10 | `TIME-ONLY` | только фейки (stun + ClientHello 4pda.to) с устаревшим TCP timestamp, без разрезки |
| 11 | `CORE-STUN2` | фейки (stun2 + sferum.ru) и разрезка с ложным началом (seqovl 664) |
| 12 | `CORE-STUN` | как `CORE-STUN2`, первый фейк stun |
| 13 | `HOST-STUN2` | фейки (sochi.park + stun2) и подмена имени хоста на mail.ru (hostfakesplit с порядком `altorder=1`, как у Flowseal) |
| 31, 32 | `SOFT-STUN2`, `SOFT-STUN` | мягкие версии для сайтов. При первой установке выбирается `SOFT-STUN2` |
| 21, 23 | `Z2-BASE`, `Z2-YT` | варианты из документации zapret2 |
| 1, 3, 4, 6–9 | `MIX-SPLIT`, `HOST-MIX`, `SEQ-SPLIT`, `SPLIT-B1`, `SPLIT-DUAL`, `FAKE-SEQ`, `HOST-ONLY` | остальные ALT Flowseal |
| 40 | `FS-BASE` | обычный `general.bat` Flowseal с разрезкой с ложным началом без фейков |
| 41 | `FS-EXP` | экспериментальная Flowseal с фейком sferum и разрезкой с ложным началом из stun2 |
| 42–44 | `TLS-ONLY`, `TLS-S2-SEQ`, `TLS-S2-TIME` | только фейки, без разрезки |
| 46–48 | `TLS-MIX`, `TLS-SEQ`, `TLS-TIME` | стандартный фейк с SNI google, badseq или timestamp и разные разрезки |
| 50–52, 57–61 | `WHITE-01`, `WHITE-02`, `WHITE-03`, `WHITE-01-03`, `WHITE-04-LITE`, `WHITE-05`, `WHITE-06`, `WHITE-01-PLUS` | варианты `SOFT-STUN2` с именами из белых списков провайдеров. Пакеты уходят к тому же серверу, что и настоящий запрос |
| 54–56 | `SPLIT-REV`, `AUTO-TTL`, `TCP-SUM` | варианты обратного порядка, TTL и контрольной суммы |
| 70, 71 | `SOFT-NO-STUN`, `SOFT-STUN-2ND` | варианты `SOFT-STUN2`, начинающиеся с ClientHello |

С версии 1.8 общий TCP-профиль `WHITE-04-LITE` использует 6 повторов фейков со STUN.

Новые стратегии (в файле есть строка `# since:` с версией) первый быстрый автоподбор после обновления проверяет сам. Дальше они остаются в нём, только если попали в круги автосмены. Повторный быстрый подбор откладывает явно слабые варианты по результатам только этой сети. Основная, близкие по результату и лучшие для отдельных сервисов остаются. Смена сети или входных файлов отменяет пропуски. Отложенные варианты перепроверяются через пять следующих прогонов или семь дней. Полный тест и ручной выбор включают все 36 стратегий.

Во время теста видны TCP/TLS в мс, баллы по сервисам, повторы, зависания, ухудшения обычных сайтов и прошедшее время. Полные результаты каждого прогона сохраняются в `runtime\test-native-<номер>.txt` и `.json`; последний отчёт — `runtime\test-last.txt`. Если финальная комбинация не подтвердилась, прежние настройки сохраняются, а измерения и история быстрых пропусков не теряются.

Какая стратегия лучшая, зависит от провайдера. В наших проверках у трёх провайдеров лучшими оказались `TIME-ONLY`, `MIX-SPLIT` и `HOST-STUN2`.

В архивном профиле `SYN-DATA` сохраняется IPv4-условие общего TCP-профиля. Смешанные круги с таким условием собираются отдельно для IPv4 и IPv6. У `FS-EXP` остаются четыре явно отмеченных отличия переноса: QUIC ограничен UDP443, неизвестный голосовой UDP не перенесён, исключение `fonts.googleapis.com` из IPSet-профиля не перенесено, а для неизвестного игрового TCP без заданного фейка оставлен прежний вариант с 256 нулевыми байтами. Это не заявление об эквивалентности исходным профилям. Область списков и игровые исключения задаются этой сборкой.

Мост Telegram учитывает включённый в Windows локальный HTTP-прокси для HTTPS (например, Happ), даже когда TUN выключен. Он заново читает эту настройку при новых соединениях. Поддерживается HTTP CONNECT на loopback без авторизации; PAC/WPAD, удалённый или SOCKS-прокси этим путём не используются. Системные настройки и маршрут игры мост не меняет.

## Частые проблемы

**Discord не запускается или висит на загрузке.** **Инструменты → 8** очистит его кэш, как у Flowseal: вход и настройки останутся. Если Discord запускали при включённом прокси, а потом прокси выключили, его надо перезапустить — проверка обходов (пункт **6**) это заметит.

**Telegram не работает, тормозит, не грузятся фото и видео.** В `zapret-rust.exe` встроено Rust-ядро на основе [TG WS Proxy от Flowseal](https://github.com/Flowseal/tg-ws-proxy) v1.11.4: Telegram Desktop подключается к нему как к локальному MTProto-прокси, а компонент использует WebSocket и резервные пути CF. Python, отдельный TG WS Proxy и его иконка в трее не нужны. Пункт **4** включает компонент и даёт ссылку подключения; прежние порт и secret сохраняются. Запуском, остановкой и обновлением ядра управляет zapret-rust. Настройки и журналы находятся в `runtime/tgws`, в архив сборки они не входят. Если прокси в Telegram выключен, подключите его снова после запуска компонента. Прослушиваемый локальный порт сам по себе не подтверждает доступность Telegram.

**Discord работает, а голос нет.** Обычно мешает программа, которая сама перехватывает трафик:
- игровой ускоритель (ExitLag и т. п.);
- прокси-клиент в режиме системного прокси: через него идёт TCP, а голос (UDP) — напрямую, мимо прокси.

Закройте их полностью и перезапустите Discord (трей → Quit Discord). Если не помогло — **Инструменты → 1 → 2** (трекер, Discord): посидите минуту в голосовом канале, трекер покажет, отвечает ли голосовой сервер.

**NBA 2K27 лагает: статтеры, FPS проседает посреди матча.**
- Часть адресов сервера `api.quago.io`, куда игра во время матча шлёт запись поведения игрока, провайдер режет по IP, и на них игра подвисает. Проверка обходов (пункт **6**) предложит закрепить в hosts рабочие адреса. Они будут перепроверяться при каждом запуске обхода.
- Если не помогло, включите на матч трекер (**Инструменты → 1**). В итоге он покажет рывки игры, соединения рядом с ними и серверы, которые не приняли подключение. Пришлите итог в обсуждения или в контакты ниже.

**Easy Anti-Cheat: «unable to authenticate» (fee12ea9).** Выключите автосмену (**Настройки → 2**) и проверьте, что в `lists\ipset-user.txt` не попали сети Take-Two. Серверы 2K сборка исключает сама.

**Dota 2 или другая игра Steam: не нажимается «Играть», нет цен на предметы.** Обычно Steam запустили при включённом прокси (Happ и т. п.), а потом прокси выключили: Steam запомнил его и шлёт запросы в пустоту. Перезапустите Steam полностью (меню Steam → Выход) — проверка обходов (пункт **6**) это заметит и предложит сама.

**Happ запущен, но подключение выключено.** Пункт **6** различает процесс клиента, текущие настройки прокси Windows и маршруты TUN. Сам процесс не доказывает включённое подключение. Если системный прокси включён, а его локальный порт не слушает, приложения могут остаться без сети. Если прокси вам сейчас не нужен, выключите «Использовать прокси-сервер» в настройках Windows; если нужен — проверьте подключение в клиенте. PAC применяется по правилам скрипта и не означает, что весь трафик идёт через прокси.

**Другая игра с обходом работает хуже, чем без него** (не находит матч, вылетает, ругается античит). Её серверы, скорее всего, стоят у хостингов из списков Flowseal. Запустите игру и трекер (**Инструменты → 1**, имя процесса игры), поиграйте пару минут, затем **Инструменты → 6** — сборка предложит исключить эти сети из обхода.

**Steam долго качает, сайты долго открываются.** Пункт **6**: у некоторых провайдеров часть сетей IPv6 не отвечает, а Windows пробует IPv6 первым. Проверка предложит «предпочитать IPv4».

**Перестал подключаться Telegram (часто после ExitLag или VPN).** Пункт **6**. Пока трафик шёл через ускоритель, соединения рвались, и в автосписок попадали адреса серверов Telegram, после чего обход ломал его запасной канал. Начиная с zapret 1.0 такие адреса убираются сами при каждом запуске обхода, а проверка показывает их, если они появились снова.

**Как выбрать игры.** Откройте **Настройки → 3 → 7**. Введите имена процессов, например `NBA2K27.exe`. Несколько имён разделяйте символом `|`. Для новой игры откройте **Инструменты → 2**, выберите её EXE и подтвердите сохранение. Пока идёт минутная запись, войдите в сетевой режим или подключитесь к матчу. Сканер сохранит точные адреса TCP и UDP в отдельный список игры. Если игра сменила серверы, повторите запись. Чтобы убрать игру, удалите её имя из выбора. Пункт 6 игрового фильтра выключает его целиком.

На игровых портах специальные правила применяются к адресам выбранных игр. Если другое приложение подключится к тому же IP на подходящем порту, правило также сработает. Общие правила сайтов и Discord действуют независимо.

**Обход или автозапуск не запускается.** Меню само покажет причину: что ответила Windows и что написал winws2. Если сбоит только служба автозапуска, обход запустится без неё. Причина попадает и в отчёт (**Инструменты → 4**). **Инструменты → 5** (диагностика) запустит winws2 в окне. Частые причины:
- антивирус удалил или блокирует `WinDivert64.sys` или `winws2.exe`;
- «Целостность памяти» (Безопасность Windows → Безопасность устройства → Изоляция ядра) не пускает драйвер WinDivert;
- запущен другой обход;
- в пути к папке русские буквы.

Не помогло — напишите мне (см. «Связь») и приложите отчёт: **Инструменты → 4**.

## Как это устроено

- Профили повторяют `general (ALT*).bat` Flowseal с Game Filter «TCP и UDP» (порты 1024–65535) и IPSet «loaded».
- Контроллер передаёт параметры winws2 в командной строке. Нативная Windows-сборка движка также читает `@config` через Rust-парсер. Общий список стратегий описан один раз шаблоном zapret2, чтобы уложиться в предел Windows 32767 символов.
- Из UDP 443 в драйвер попадают только пакеты QUIC Initial, а не весь поток видео.
- Фейки портятся устаревшим TCP timestamp. Если сервер timestamps не поддерживает, фейк портится иначе (`lua\fooling.lua`: MD5-опция и сдвиг sequence), а не уходит целым.
- Перед каждым запуском winws2 проверяет параметры и формирует полный сетевой фильтр. Фильтр дополнительно проверяет компилятор входящей в сборку WinDivert DLL без открытия драйвера. Ошибка обнаруживается до остановки работающего обхода.
- Рейтинг стратегий по последнему автоподбору хранится в `runtime\test-rank.txt`. По нему собираются круги автосмены сайтов, YouTube и Discord: в них попадают стратегии, которые дают не меньше 60% прироста лучшей, но не больше пяти. Круг игр от рейтинга не зависит.
- Какие адреса открыла каждая стратегия, хранится в `runtime\test-cover.txt`: по нему собирается круг. Память автосмены — в `runtime\ring\`: только сайты и подсети, которым подошла не первая стратегия. Эти файлы остаются на вашем ПК и в отчёт не попадают.
- В современной конфигурации подсказки памяти действуют до 30 дней с последнего подтверждения. В круге хранится до 2000 записей; заполнение вытесняет старые постепенно. Снимок до 256 КБ сохраняется атомарно по таймеру, детектор пакетов его не переписывает.
- В оперативном индексе обучаемой автосмены хранится до 4096 сайтов суммарно по профилям. Старые записи вытесняются постепенно; открытое соединение удерживает свою запись до завершения, но после вытеснения не меняет общую память поздним результатом. Это ограничение истории сайтов, а не всей памяти процесса. Игровые профили используют прежнее состояние автосмены.
- Рейтинг и покрытие применяются только к той же сети, настройкам обработки и содержимому стратегий, списков и файлов обхода. При смене Wi-Fi или несовместимых входов используются стандартные круги до нового автоподбора. Старые результаты без контекста сохраняются в точных копиях `.v1.bak` перед первой перезаписью. Итоговая проверка строит новый круг в памяти и публикует его только после успеха.
- Контекст сети учитывает также метрику интерфейса каждого значимого IPv4/IPv6 маршрута. Смена приоритета Wi-Fi или TUN инвалидирует старые результаты и подтверждение памяти даже при прежних шлюзе и метрике маршрута. Недоступная метрика означает неизвестный контекст.
- При обновлении кода фоновый наблюдатель снимает подтверждение сетевой памяти и передаёт работу новому экземпляру после освобождения своей блокировки. Он подтверждает только ту реализацию, которую действительно загрузил; временно недоступный файл означает неизвестное состояние с повторной проверкой. Изменения только списков или настроек не требуют его перезапуска.
- Баллы последних 3 прогонов каждой стратегии за 30 дней хранятся в `runtime\test-scores.txt`. По их среднему автоподбор решает, предлагать ли новую основную стратегию; круги автосмены строятся по последнему прогону.
- До и после автоподбора повторяются контрольные HTTPS-запросы без обхода. Если их доступность или задержки заметно изменились, новая история и рейтинг не применяются. Контроль получает только заголовки ответа, максимум с пяти адресов.
- Порядок стратегий воспроизводится по seed из отчёта; при нескольких раундах соседние идут в обратном порядке. Исходные попытки до объединения повторов сохраняются в `runtime\test-attempts-*.jsonl`, порядок — в `test-order-*.json`, оценка контроля — в `test-control-*.json`. Полные URL в журнал попыток не попадают. Это проверка повторяемости HTTPS, а не измерение игрового пинга.
- Таблица показывает баллы текущего прогона. Предложение для основной учитывает среднее совместимых прогонов и порог смены2балла; причина решения записывается в отчёт. Строка «Основная после теста» в начале отчёта показывает фактический итог: применена ли смена или сохранена прежняя стратегия. Если рабочая комбинация не прошла финальную проверку, кандидат не применяется.
- HTTP-код сам по себе не даёт успешный балл: передача должна завершиться либо достичь заданного бюджета тела. Заголовок 200 перед зависшим или оборванным телом остаётся сбоем; завершённый 403/404 допустим. Каждая запись содержит причину завершения и фактически наблюдённые объёмы.
- Полный автоподбор по умолчанию выполняет до 32 запросов одновременно в первом проходе и до 8 в повторах. Быстрый подбор использует 16 и 4. Пауза перед повторами составляет 250 мс. Для полного прогона с меньшей нагрузкой используйте `bin\zapret-rust.exe test --full --parallel 16`. Параметры прогона видны в JSON-плане (`--plan-only`) и отчёте.
- Исходящий UDP к четырём исключённым IPv4 сетям Take-Two отфильтровывается до передачи в winws2. Для небольшого корректного списка исключения драйвера и профилей фиксируются вместе при запуске; после изменения внутреннего `lists/ipset-taketwo.txt` нужен новый запуск. Пользовательские списки сохраняют прежнее перечитывание. Для большого или смешанного IPv4/IPv6 списка применяется прежний вариант с файлом.
- Наблюдатель связи защищает обучение автосмены сайтов при подтверждённом разрыве Wi-Fi: по переходу состояния отслеживаемого адаптера или свежему WLAN8003 этого интерфейса. На20с новые соединения не участвуют в обучении; затронутые старые соединения не портят память поздними ошибками. После паузы новые соединения снова учатся. Журнал недоступен, сайт не ответил или пропал heartbeat — это не доказательство разрыва и не причина бесконечно запрещать автосмену. Наблюдение локальное, раз в5с; короткий сбой без доступного события может быть пропущен. Игровой TCP сохраняет прежние детекторы.
- Нативный трекер сохраняет наблюдённые ETW-соединения, счётчики и метаданные точного процесса. Ограниченные активные пробы задержки и сведения о провайдере подписаны своим временем наблюдения; пробы после записи не объясняют предшествующие рывки. В инструменте задержки отдельно измеряются ICMP и TCP; P95 появляется после 20 ответов.

## Папки

| Папка | Что в ней |
|---|---|
| `bin\` | `zapret-rust.exe` со встроенным Telegram, резервный `zapret-rust-recovery.exe`, фоновый `zapret-rust-worker.exe`, закреплённые winws2, WinDivert и Cygwin |
| `lua\` | библиотеки zapret2 и Lua-адаптеры Rust-модуля |
| `fake\` | фейковые пакеты Flowseal |
| `strategies\` | стратегии |
| `lists\` | списки Flowseal; свои добавления — в `*-user.txt`; сети Take-Two; копия hosts Flowseal |
| `tools\` | данные целей и происхождения компонентов; старые скрипты остаются только в исходном репозитории |
| `runtime\` | настройки, рейтинг, отчёты и логи (создаётся сам) |
| `dev\` | проверки и сборка из исходников; пользовательский ZIP эту папку не содержит |
| `native\` | исходники Rust workspace; в пользовательский ZIP не входят |

Списки winws2 перечитывает сам, перезапуск после правки не нужен.

## Обновление и удаление

Пункт **8** показывает уведомления, а **Настройки → 9** проверяет и устанавливает нативный архив `zapret-rust-native-v<версия>.zip` из GitHub. Проверяются SHA256 архива, полный каталог файлов и закреплённые компоненты. Настройки, рейтинг и личные списки сохраняются. Обычный архив прежней PowerShell-версии нативный установщик не принимает.

До остановки обхода установщик проверяет новый пакет, сохраняет резервный нативный вход `bin\zapret-rust-recovery.exe`, прежние файлы и защищённый журнал в `runtime\update\`. Если авария оставит основной EXE отсутствующим, `zapret-rust.bat` запускает резервный вход. Перед восстановлением проверяются все резервные копии и внешние изменения файлов. После установки меню нужно открыть заново.

Чтобы удалить сборку: **Настройки → 11** убирает из Windows всё, что она ставила (обход, драйвер WinDivert, службу, задачи планировщика, записи zapret-rust в hosts, права на папки). Потом закройте меню и удалите папку. Если пользовались мостом Telegram, выключите прокси в Telegram Desktop.

Чтобы заменить папку вручную, не удаляя сборку:

1. **Настройки → 6** (если ставили службу), **Настройки → 7** (если включали автонастройку) и **Настройки → 10** (если включали уведомления).
2. Пункт **2**: он останавливает обход и выгружает драйвер WinDivert. Без этого Windows не даст удалить `bin\WinDivert64.sys`.
3. Закройте меню и замените папку. Чтобы сохранить настройки и рейтинг, перенесите `runtime\` в новую папку.

Ранее сборка называлась zapret, а до её версии 1.0 — NBA2K27-zapret2 (версии 2.0–3.3, запуск через `NBA2K27.bat`). Прежние имена регистрации Windows распознаются для совместимости; запуск текущей версии — `zapret-rust.bat`.

Что сборка меняет в Windows и как это вернуть:
- **TCP timestamps** включаются для фейков, так же делает Flowseal. Вернуть: `netsh interface tcp set global timestamps=disabled`.
- **«Предпочитать IPv4»** и **записи hosts** (если включали проверкой обходов): пункт **2** перед удалением предложит вернуть их как было.
- **Права на папки с кодом** (см. «Безопасность»): пункт **2** возвращает обычные, иначе Проводник при удалении спросит права администратора.

## Безопасность и приватность

**Защита от подмены.** Сборка работает с правами администратора, а служба и автонастройка — с правами SYSTEM. Чтобы этим не воспользовалась чужая программа:
- перед каждым запуском файлы zapret2 (`bin\`, библиотеки `lua\`) сверяются с SHA-256 официального релиза. Если файл изменён, обход не запускается;
- при запуске меню папки с кодом (`bin`, `lua`, `tools`, `strategies`, `fake`, `windivert`) и `.bat` закрываются на запись для всех, кроме администраторов и SYSTEM. По умолчанию папка в `C:\` наследует право «Изменение» для всех пользователей, и программа без прав администратора могла бы подменить скрипт. Папки с данными (`lists\`, `runtime\`) остаются как были;
- скачанное из интернета (списки Flowseal, набор хостингов для теста) никогда не запускается как код: это только данные, и битые или подозрительные файлы не ставятся.

**Компоненты и сертификаты.** Сборка не ставит сертификаты и не трогает хранилище сертификатов Windows. В неё входят zapret2 (winws2 от bol-van), драйвер WinDivert, библиотека Cygwin и встроенное Rust-ядро на основе TG WS Proxy Flowseal. Исходники компонентов открыты; бинарные файлы движка закреплены SHA-256, а приложение со встроенным Telegram проверяется каталогом пакета. Стратегии «белый» лишь подписывают фейковый пакет именем сайта из белого списка (max.ru, vk.com, gosuslugi.ru). На эти сайты ничего не отправляется, ничего от них не скачивается и не ставится. Проверка обходов (пункт **6**) предупредит, если в Windows установлен российский корневой сертификат (его просят поставить для госсайтов): с ним в системе HTTPS можно подменить незаметно.

**Сетевые обращения.** Проверки и обновления сборки используют HTTPS. Включённый TG WS Proxy отдельно передаёт трафик Telegram через предусмотренные upstream-компонентом пути. Основные служебные обращения:
- **ipwho.is**, запасной **ipinfo.io** — узнать провайдера и страну. Без этого проверка не поймёт, идёт ли трафик напрямую. Трекер так же узнаёт, где серверы игры;
- **GitHub** — свежие списки Flowseal, номера новых версий и, по вашей команде (Настройки → 9), архив новой версии zapret-rust;
- **Telegram и резервные CF/H2-адреса TG WS Proxy** — подключение Telegram Desktop, если компонент включён через **Инструменты → 8**;
- **hyperion-cs.github.io** — набор хостингов для теста;
- **Cloudflare DoH (1.1.1.1)**, запасной **Google DoH (8.8.8.8)** — сравнение DNS в диагностике и отчёте для фиксированных проверочных имён; история посещений не отправляется;
- **проверочные сайты автоподбора** (`tools\targets.txt`): на хостинги уходят до 64 КБ тестовых байт.

**Что в отчётах.** Отчёт (Инструменты → 4) и проверка провайдера (Инструменты → 3) делаются, чтобы их пересылать, поэтому:
- последняя часть вашего IP и имя пользователя Windows в путях скрыты;
- список сайтов из автосписка, по которому видно, какие сайты вы открывали, добавляется только с вашего согласия;
- подробный лог winws2 добавляется только с вашего согласия;
- secret локального Telegram-прокси и ссылки подключения скрываются в общем отчёте.

Все логи лежат только в `runtime\` на вашем ПК, удалить их можно в любой момент.
